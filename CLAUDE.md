# CLAUDE.md

All project guidance lives in **[AGENT.md](./AGENT.md)** — read it first. Short version of the rules:

- Read `TREESTRUCTURE.md` to locate files **before** grepping; keep it updated when files change.
- Read `TODO.md` for open work; tick items as done.
- Log every notable change in `CHANGELOG.md` under `[Unreleased]`.
- `SRS.md` is the requirements source of truth.
- Verify UI changes in the browser; run `npm run typecheck` and `npm test`.
